# Унифицированный драйвер AIC8800D80

Драйвер устанавливает оба совместимых комплекта firmware. Текущая firmware
используется по умолчанию, поскольку `chip_mcu_id` сам по себе не определяет
размер доступного окна загрузки:

- `mcu0` - текущая firmware и новая таблица патчей;
- `mcu1` - проверенная firmware Radxa SDK V3 и совместимая таблица патчей.

Для устройств, на которых загрузка текущего образа подтверждённо завершается
ошибкой, legacy-профиль можно задать в `/etc/modprobe.d/aic8800.conf`:

```text
options aic_load_fw d80_firmware_profile=legacy
options aic8800_fdrv d80_firmware_profile=legacy
```

Допустимые значения: `auto`, `current`, `legacy`. `auto` и `current`
используют текущую firmware; `legacy` никогда не выбирается только по MCU ID.
Одинаковое значение необходимо задавать обоим модулям, чтобы загрузчик,
таблица патчей и пользовательские настройки радиотракта использовали один
комплект файлов.

Загрузка выполняется стандартным API ядра `request_firmware()`. Для обычной
установки параметр `aic_fw_path` указывать не требуется. Если он необходим,
значение должно быть относительным каталогом внутри `/lib/firmware`.

## Установка

```bash
sudo ./install.sh
sudo reboot
```

Установщик копирует каталоги firmware рекурсивно, собирает три DKMS-модуля и
обновляет initramfs. Встроенные адаптеры Broadcom он не включает обратно.

## Проверка

```bash
sudo journalctl -k -b --no-pager | grep -E \
  'chip_id|chip_mcu_id|firmware profile|Firmware Version'
ethtool -i ИМЯ_ИНТЕРФЕЙСА
lsmod | grep -E 'aic8800|aic_load_fw|aic_zlp_quirk|btusb'
```

Для MCU1 в журнале должны присутствовать выбор профиля MCU1 и сообщение о
Bluetooth cache fix. `ethtool` должен показывать `aic8800_fdrv`, версию модуля
и версию firmware.

## Новые возможности

- передача кадров через monitor-интерфейс с проверкой radiotap-заголовка;
- ZLP-обработка Bluetooth ACL для проверенного `368b:8d81`; вариант
  `a69c:8d81` протестирован и намеренно исключён, поскольку ZLP вызывает
  ошибки передачи `-90`;
- корректная диагностика драйвера и firmware через `ethtool`;
- безопасная обработка ошибок выделения памяти и ответа firmware.

WoWLAN, A-MSDU TX, beamforming и USB aggregation не включены: эти возможности
требуют отдельно подтверждённой поддержки со стороны конкретной firmware.
